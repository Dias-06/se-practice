## 6. Reflection (200–300 words)

Writing the manual code in JavaScript was very simple. I could easily control how to filter wrong numbers like `-5` or `101`, and handle text like `abc`. I also wrote code to stop division by zero when the list is empty, so the console printed a clear message.

The AI tool, Rocket, made the work faster at first. In just two minutes, it generated a full website with nice buttons and cards. However, Instead of making a simple script that reads a list, it created a complex website. Also, it did not filter wrong values in code logic at first; it just blocked typing them in the form.

I prefer my manual JavaScript version because I wrote it myself and I understand every single line. The AI version looks much better, but there is too much extra code that I did not ask for.

In conclusion, AI is great for quickly building UI and layout. But a human developer must still check the code, test edge cases, and make sure the program follows all the assignment rules correctly.
